# Conjugator

Permet d'analyser le Mode, Temps et Pronom Personnel d'un verbe conjugué

**▶ Démo en ligne : [https://yoannservices.github.io/conjugator/](https://yoannservices.github.io/conjugator/)**

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000.

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
